## ✨ О проекте

Telegram Translation Bot — это мощный и многофункциональный бот для перевода текстов с поддержкой более 9 языков. Бот включает в себя продвинутую админ-панель для управления пользователями, просмотра статистики и экспорта данных.

## 🌟 Ключевые возможности

### Для пользователей
- 🌍 **Автоматический перевод** на 100+ языков
- ⚡ **Мгновенный перевод** с автоопределением языка
- 📜 **История переводов** персональная для каждого пользователя
- 📊 **Статистика использования** с отслеживанием прогресса
- 💫 **Умный интерфейс** с интуитивными кнопками

### Для администраторов
- 👑 **Полная админ-панель** с расширенным функционалом
- 📈 **Детальная статистика** по пользователям и переводам
- 👥 **Управление пользователями** - просмотр информации и истории
- 📤 **Экспорт данных** в форматах JSON и CSV
- 🔄 **Очистка данных** с гибкими настройками периода
