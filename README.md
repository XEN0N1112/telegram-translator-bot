# Telegram Translation Bot

Умный бот-переводчик с админ-панелью.

## Функции
- Переводчик на разные языки
- История переводов
- Админ-панель
- Статистика

## Установка
1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте config.py
4. Запустите: `python bot.py`
