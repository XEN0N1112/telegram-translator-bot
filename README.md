## ✨ О проекте

Telegram Translation Bot — это мощный и многофункциональный бот для перевода текстов с поддержкой более 9 языков. Бот включает в себя продвинутую админ-панель для управления пользователями, просмотра статистики и экспорта данных.

### 🌟 Ключевые возможности

- 🌍 **Автоматический перевод** на 9 языков
- 📊 **Полная статистика** использования
- 👑 **Админ-панель** с управлением пользователями
- 💾 **Экспорт данных** в JSON и CSV форматах
- 📜 **История переводов** для каждого пользователя
- ⚡ **Быстрый интерфейс** с интуитивными кнопками
